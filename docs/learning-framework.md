# 学习框架（仅工作仓库）

> 这份文档不追求"学完"，只保证：每写一个模块，你能脱稿讲清它为什么存在、怎么工作、哪里会坏。

## 1. 学习比例

- 30% 读：协议、手册、库源码；
- 50% 写：自己写红区模块，AI 只做脚手架；
- 20% 讲：每周脱稿 5 分钟，录音或写笔记。

顺序不能反。只看不写，面试会露馅；只写不讲，遇到追问会卡住。

## 2. 每周学习地图

### W1：Modbus RTU 从站

**要搞懂的概念**

- RTU 帧：地址、功能码、数据、CRC；帧内/帧间间隔（1.5 / 3.5 字符）。
- 功能码 0x03/0x04/0x06/0x10 的请求/响应格式。
- 异常码 0x01–0x04；异常响应 ≠ 通信失败。
- 0x03 与 0x04 是两个独立地址空间；地址 0-based。
- RS485 差分、终端电阻、共地；DE/RE 方向控制。
- UART DMA + IDLE 判帧；为什么 115200 不能靠 1ms 定时器。
- CRC16：poly 0xA001、初值 0xFFFF、低字节先发；测试向量 `"123456789"` → 0x4B37。

**要读的代码**

- `third_party/nanomodbus/nanomodbus.c`：看 server 如何取帧、校验、分发回调。
- `device-f103/App/modbus_slave/mb_slave.c`：看协议栈如何和寄存器模型对接。
- `device-f103/App/register_map/mb_regs.c`：看空间/权限/异常码映射。

**要自己写**

- `rs485_port.c`：DMA + IDLE + DE/RE + TC 等待。
- `board_config.h`：按实际板子填引脚。

**本周 5 个问题**

1. 为什么 DMA 发送完成不能立刻拉低 DE？
2. 3.5 字符静默在 115200 下是多少微秒？IDLE 中断如何近似？
3. 从站返回异常码 0x02，主站应不应该判它离线？
4. u32 寄存器为什么要偶地址对齐、ABCD 高字在前？
5. 广播写 0x06 为什么不能响应？

**验收**

- 1000 次 0x03/0x04 读无错；
- 非法地址返回 0x02，CRC 错丢弃；
- 广播写执行但不响应；
- 故障注入 30s 自恢复。

### W2：F407 主站

**概念**：事务状态机、超时、重试、总线周转、单事务占用、异常响应分类。

**要读**：`docs/AI-HANDOFF.md` 6.2；nanomodbus client 调用流程。

**要自己写**：`mb_transaction.c`、`mb_transport.c`（状态机与超时）。

**5 个问题**

1. 一次事务从 BUILDING 到 COMPLETED 经过哪些状态？
2. 重试为什么放回队尾，而不是原地重试？
3. 超时 50ms 是怎么算出来的？20 个寄存器帧时间多少？
4. 写请求如何防止饿死采集？
5. 从站返回异常码时，事务算成功还是失败？

### W3：FreeRTOS 任务与队列

**概念**：任务优先级、队列、互斥、临界区、栈余量、看门狗分级喂狗。

**要读**：FreeRTOS 官方 API 文档；`uxTaskGetStackHighWaterMark`、`uxQueueMessagesWaiting`。

**要自己写**：任务创建、RequestQueue/ResultQueue、HealthMonitor。

**5 个问题**

1. 为什么只允许 Rs485TransportTask 访问 UART？
2. 队列满时丢哪一类请求？为什么？
3. 优先级怎么排？会不会优先级反转？
4. 什么条件下才喂狗？
5. 栈大小怎么估？high water mark 怎么看？

### W4：调度与镜像（简历门槛）

**概念**：周期调度、离线降频、恢复上线、寄存器镜像、有效期、32 位原子更新。

**要读**：`docs/AI-HANDOFF.md` 6.3/6.4；现有调度器代码。

**要自己写**：`scheduler.c`、`register_model.c`，完成 4 从站联调。

**5 个问题**

1. 连续失败 3 次离线、连续成功 2 次上线，阈值为什么这么定？
2. 离线后轮询周期怎么变？谁决定？
3. 32 位值如何避免半新半旧？
4. 镜像的 valid/timestamp/quality 各解决什么问题？
5. 一个从站掉线，如何证明其他从站不受影响？

### W5：Linux 服务（可选）

**概念**：epoll、非阻塞 socket、半包/粘包、帧头 CRC、SQLite WAL/批量提交。

**要读**：`man epoll`、SQLite WAL 文档、现有 `linux-server` 代码。

**要自己写**：epoll 事件循环、连接缓冲、入库线程。

**5 个问题**

1. 为什么不能假设一次 recv 拿到完整一帧？
2. EPOLLIN/EPOLLOUT 分别什么时候注册？
3. 半包和粘包分别怎么处理？
4. 为什么批量提交 + WAL？写放大是什么？
5. 断线重连后，序号/心跳怎么恢复？

### W6：LwIP 与联调（可选）

**概念**：RMII、PHY（YT8512C）、TCP 客户端、缓冲区、重连。

**要读**：LwIP raw API、YT8512C 数据手册、探索者 V3 原理图。

**要自己写**：NetworkTask、联调脚本、稳定性报告。

## 3. 学习资料

- Modbus Application Protocol V1.1b；
- Modbus over Serial Line V1.02；
- STM32F103 参考手册：USART、DMA、NVIC；
- FreeRTOS 官方文档：任务、队列、信号量、内存；
- nanoMODBUS 源码与 examples；
- pymodbus 文档；
- 《嵌入式软件测试》相关章节（故障注入、边界值）。

## 4. 不要做的事

- 不看协议直接抄工程；
- 让 AI 写红区，自己只跑通；
- 用"能通信"代替"异常也正确"；
- 把设计目标写成实测结果；
- 跳过 W1 直接做 Linux。
