**基于 STM32F407（FreeRTOS）与 Linux 的工业边缘通信网关**　2026.12 – 2027.01　独立开发

**技术栈：** C、STM32F103C8T6 / F407ZGT6、FreeRTOS、Modbus RTU、RS485、UART DMA、TCP/IP、epoll、SQLite

**项目简介：** 自研三层工业边缘网关：感知层（F103，4 个逻辑 Modbus RTU 从站 + 真实传感器采集）经 RS485 接入边缘层（F407，FreeRTOS 主站网关：寄存器镜像 + 本地闭环控制），再经 TCP 上报服务层（Linux C，epoll + SQLite 持久化），实现"采集—决策—控制—存储"全链路，断网时现场仍自治可控。

**主要工作：**

1. **从站协议栈与底层适配（感知层）：** 基于 UART DMA + 空闲中断实现 115200 波特率下变长帧接收与帧界判定；集成 nanomodbus（MIT）并自研 RS485 移植层，实现 0x03/0x04/0x06/0x10 及异常响应；DE 方向脚严格等待 UART TC 置位后切换，逻辑分析仪实测消除末字节截断；单板模拟 4 个逻辑从站，内置 6 种故障注入（无响应 / 坏 CRC / 延迟 / 截断等）。

2. **主站事务状态机与多从站调度（边缘层）：** 设计非阻塞事务状态机（发送→等 TC→等响应→校验→重试），单事务独占总线，从机制上避免多任务串口资源竞争；50ms 超时（约 10 倍帧时间余量）、重试放回队尾不阻塞其他设备、连续 3 次失败判离线并降频轮询（500ms→2s/5s/10s）、连续 2 次成功自动恢复；【实测】0x03/0x04 各连续读取 1000 次、【N】次错误。

3. **寄存器镜像与边缘闭环控制：** 建立共享寄存器缓存解耦上下行数据，点级镜像带时间戳与有效期，32 位点一次性更新避免半新半旧；控制指令采用"写穿透 + 从站回显确认"语义，确认后才更新状态，保证缓存与现场一致；实现温度阈值 + 回差（30.0°C/28.0°C）本地闭环控制执行器，云端断连不影响现场控制。

4. **Linux 通信服务（服务层）：** C 语言 epoll 事件循环，自定义 26 字节二进制协议头（魔数 / 版本 / 序列号 / 双 CRC）处理拆包粘包与心跳重连；SQLite WAL 模式批量入库，"变化触发 + 最小 1s 间隔 + 保留期"策略控制数据量，点级质量标记（正常 / 过期 / 通信错）；【实测】24h 连续运行无复位、入库【N】行。

5. **测试体系与工具链：** 寄存器表 CSV 单一来源，生成器同步产出 C/Python/文档三端代码；Python 实现 Modbus 主站测试器、网关模拟器与故障注入脚本；【实测】20 个故障场景（拔线 / 坏帧 / 超时 / 离线恢复）全部通过。

**项目成果：** F103 从站 / F407 网关 / Linux 服务三层全自研，代码与设计文档开源于 GitHub；【一句话总结指标：1000 次连读错误数、离线恢复时间、24h 运行结果】。
